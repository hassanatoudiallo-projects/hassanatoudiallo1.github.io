# Portfolio Data Analyst

Site portfolio personnel en HTML/CSS, à publier avec GitHub Pages.

## À personnaliser
- Remplacer `[Prénom Nom]` et les liens entre crochets dans `index.html`.
- Ajuster les descriptions des projets pour refléter précisément les réalisations.
- Ajouter ensuite des captures et des fichiers de projet.

## Publier avec GitHub Pages
Dans le dépôt GitHub : **Settings → Pages → Build and deployment → Deploy from a branch**.
Choisir la branche `main`, le dossier `/ (root)`, puis cliquer sur **Save**.
